# Security Policy

## Reporting

For this portfolio project, open a private security advisory in the hosting repository if a security issue is found.

## Rules for contributors

- Never commit real credentials, tokens, certificates, account IDs, private endpoints, PHI, PII, or employer data.
- Use synthetic identifiers only.
- Cloud applies are manual and must use a disposable/sandbox account.
- Prefer short-lived identity federation over long-lived access keys.
- Do not make the EKS control plane or database broadly reachable for convenience.
